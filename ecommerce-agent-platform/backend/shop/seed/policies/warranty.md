# Warranty (synthetic store policy)

Electronics carry a 12-month manufacturer warranty from the delivery date. The warranty covers manufacturing defects. It does not cover accidental damage, water damage beyond the stated rating, or normal battery wear.
To make a claim, create a support request with your order number and a description of the fault.
